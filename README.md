# Юрий Макаров — авторский сайт (статический MVP)

Одностраничный сайт без сборщика и сторонних CDN: локальные шрифты с кириллицей, изображения, CSS и vanilla JS. Его можно разместить на любом статическом хостинге с HTTPS.

## Что уже работает

- Адаптивные страницы-рубрики: главная, аниме, фильмы, хорроры, авторские тексты, планетарий и об авторе.
- Цветовая система по рубрикам: базовая циан/фуксия; аниме — ультрафиолет; фильмы — холодный изумруд; хорроры — рубиновый нуар; авторские тексты — кобальт.
- Одинаковая шрифтовая система во всём проекте: Oswald + Rubik + IBM Plex Mono; файлы шрифтов лежат локально.
- Поиск и фильтры по материалам; отдельные страницы чтения статей; шаринг материалов в Telegram и VK.
- Интерактивный планетарий с ядром Солнце/Луна, орбитой личных функций, социальным и коллективным уровнями; HUD-подсказки, профили планет, материалы по теме и переключаемые аспекты.
- Favicon SVG, иконка для мобильного экрана, webmanifest и OG-карточки для главной, рубрик и статей.
- Статические share-страницы в `share/`: дают каждой рубрике/статье собственные Open Graph title, description и image, после чего переводят посетителя на нужное место сайта.
- Уважение `prefers-reduced-motion`, клавиатурная навигация по планетам, мобильное меню.

## Запуск локально

Из папки `yuriy-makarov-site`:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем открыть `http://localhost:8000`.

## Перед публикацией нужно заполнить `site-settings.js`

```js
window.SITE_SETTINGS = {
  siteUrl: "https://ваш-домен.ru",
  bookingUrl: "ссылка-на-запись-или-форму",
  contactEmail: "почта-по-желанию",
  consultationPrice: "утверждённая-цена-или-диапазон",
  social: {
    telegram: "ссылка-на-канал-или-чат",
    vk: "ссылка-на-сообщество",
    youtube: "ссылка-на-канал"
  }
};
```

После выбора домена заменить относительный адрес `og:image` в `index.html` на абсолютный HTTPS URL. В share-страницах `share/*.html` также заменить относительные `og:image` на абсолютные адреса вида `https://ваш-домен.ru/assets/images/og-....jpg`; это нужно, чтобы предпросмотр ссылки надёжно подхватывал изображение в Telegram и VK.

## Что оставлено незаполненным намеренно

- Реальные ссылки на TG/VK/YouTube, контакт для записи, домен и утверждённая цена.
- Портрет Юрия: пока вместо случайного стокового фото используется абстрактная авторская композиция.
- Тексты статей — редакционные первые версии, собранные из предоставленных заметок. Перед публичным запуском стоит проверить формулировки и решить, какие из них уже готовы к публикации.
- Нет эквайринга, автоматического календаря, формы, которая отправляет персональные данные, и внешней аналитики. CTA настроены так, чтобы после заполнения контактов вести на заданный адрес.
